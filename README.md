# 🔮 Mystic Tarot — Fully Interactive Streamlit App

A Python + Streamlit tarot application where the user **chooses the cards manually**.

## Features

- Full 78-card deck
- 22 Major Arcana + 56 Minor Arcana
- User-selected face-down cards
- Select / deselect cards
- Shuffle / reshuffle
- Upright / reversed orientation
- 1-card, 3-card, and 5-card spreads
- 💼 Career
- ❤️ Love
- 💰 Money
- 🌱 Personal Growth
- 🔮 Future
- Question-based readings
- Responsive Streamlit layout
- No API key or database required

## Run locally

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```
